AGROTECH — O Sistema Operacional da Empresa Rural

Manual oficial de uso com capturas de tela reais, guia de instalação do chicote de telemetria CAN Bus e protocolo de validação em campo com operadores de máquinas agrícolas.

1 Visão Geral da Plataforma & Padrão Visual 60-30-10

O AGROTECH adota a consagrada regra ergonômica 60-30-10 para garantir máxima legibilidade em ambientes de alta luminosidade solar no campo, eliminando o cansaço visual comum em sistemas legados carregados e escuros:

Figura 1: Visão Geral do Sistema com Left Sidebar, Topbar Unificado e Cards de Indicadores Design 60-30-10
Distribuição Equilibrada das Cores:
  • 60% Fundo Dominante: Off-white neutro (#F7F9F5) que previne ofuscamento óptico.
  • 30% Estrutura Secundária: Ardósia profunda (#0F172A) nos menus e cabeçalhos.
  • 10% Acentos Direcionadores: Verde Floresta Nobre (#1D4B38) reservado exclusivamente para botões de ação e status críticos.

6 Manual de Instalação Física do Chicote Telemático CAN Bus (SAE J1939 / ISO 11783)

A telemetria de precisão depende da integração do modem IoT ao barramento de dados original do trator, pulverizador ou colheitadeira:

ATENÇÃO DE SEGURANÇA ELÉTRICA: Desligue a chave geral da máquina e desconecte o polo negativo da bateria antes de iniciar a conexão do chicote!
CONECTOR DEUTSCH 9 PINOS (J1939-13 TIPO 1 / TIPO 2) (Vista Frontal) [ B: VCC ] [ A: GND ] \ / [ C: CAN_H ]---\-----/--- [ J: Ignição ] \ / [ D: CAN_L ]-----( O )--- [ H: OEM ] / \ [ E: SHLD ]----/-----\--- [ G: ISOBUS ] / \ [ F: ISOBUS ]
Pino Identificação Cor Típica Finalidade Técnica
Pino A GND (Terra) Preto Aterramento no chassi metálico do veículo.
Pino B VCC (+12V/+24V) Vermelho Alimentação contínua com fusível de 3A instalado a < 20 cm da bateria.
Pino C CAN_H (High) Amarelo Linha diferencial positiva SAE J1939 (2.5V a 3.5V).
Pino D CAN_L (Low) Verde Linha diferencial negativa SAE J1939 (1.5V a 2.5V).
Pino E CAN_SHLD Malha Nua Blindagem eletromagnética aterrada em ponto único.
Pino J Ignição (KL15) Branco Linha pós-chave para despertar e repouso automático do modem.
Regra de Ouro da Impedância: Meça com um multímetro na escala de Ohms entre o Pino C (CAN_H) e o Pino D (CAN_L) com a máquina desligada. A leitura deve ser de 60 Ohms. Os fios devem ter no mínimo 33 a 50 voltas por metro (par trançado).

7 Protocolo de Validação e Comissionamento In Loco com Operadores

Com o chicote instalado, ligue a máquina e abra o painel de Telemetria de Frotas:

Figura 7: Confronto em Tempo Real de RPM, Horímetro, Pressão de Óleo e Temperatura Comissionamento Concluído
1
Conferência de RPM (PGN 61444 EEC1)
Acelere o motor até 1.800 RPM. A leitura no AGROTECH deve bater com o tacômetro da cabine (tolerância de ±5 RPM).
2
Pressão de Lubrificação (PGN 65263 EFL_P1)
Verifique a pressão: faixa normal entre 3.0 e 5.5 bar. Alerta sonoro/visual dispara automaticamente abaixo de 1.5 bar.
3
Temperatura do Arrefecimento (PGN 65262 ET1)
Faixa nominal de 82°C a 94°C. O sistema bloqueia a máquina e alerta o gerente acima de 102°C.

14 Guia de Instalação Local e Servidor On-Premises na Sede da Fazenda

Permite que a fazenda opere com autonomia completa e latência zero (menos de 2ms), independente de oscilações do link de internet ou satélite:

Requisitos de Hardware Recomendados: Mini PC industrial ou Servidor com processador Intel Core i5/i7 ou AMD Ryzen, 16 GB de RAM, SSD NVMe 512 GB e No-break senoidal de 1.200 VA com bateria externa.
# Instalação Rápida Automatizada via Docker Compose no Linux (Ubuntu 22.04/24.04 LTS) sudo apt update && sudo apt install -y docker.io docker-compose git cd /opt sudo git clone https://github.com/empresa-rural/agtech-platform.git cd agtech-platform sudo docker compose up -d --build
1
Fixação de IP Estático na Rede da Fazenda
Configure o servidor com IP fixo (ex: 192.168.1.100) via Netplan no Linux para que os tablets e balanças sempre localizem a aplicação.
2
Roteamento para Starlink e Wi-Fi dos Silos
Conecte o servidor à porta LAN do switch central e distribua o sinal via rádios Ubiquiti/Mikrotik para os barracões e oficinas.
3
Backup Automático Diário às 02:00 da Madrugada
Script automático agendado no cron compacta o banco de dados e envia para um storage NAS ou pendrive USB externo com retenção de 30 dias.
